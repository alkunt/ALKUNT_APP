# ALKUNT

منصة عربية مستقلة لإدارة المحتوى التعليمي والأوامر والمقالات والمشتريات، باستخدام Next.js وNode.js 24 وSQLite.

- [دليل التشغيل والنشر بالعربية](README_AR.md)
- [تجهيز GitHub وربط المستودع](GITHUB_SETUP_AR.md)
- [التسويق بالبريد: الحملات والمشتركون والجدولة](EMAIL_MARKETING_AR.md)

## تشغيل محلي

```sh
npm ci
```

انسخ `.env.example` إلى `.env.local`، واضبط `APP_ORIGIN=http://localhost:3000` و`COOKIE_SECURE=false` للاستخدام المحلي فقط. أنشئ حساب المالك بأداة `npm run owner` بعد تمرير ملف البيئة إلى Node، ثم:

```sh
npm run build
npm start
```

## التحقق

```sh
npm test
npm run typecheck
npm run build
npm run test:http
```

## ملفات البيانات

| المسار | ما يحتويه |
| --- | --- |
| `data/alkunt.sqlite` | قاعدة البيانات الأساسية |
| `data/content/catalog.json` | جميع المنتجات والمقالات والأوامر والدروس وإعداداتها الحالية |
| `data/content/files/` | نسخ مرفقات المحتوى وبياناتها الوصفية |
| `data/registered-users.json` | بيانات الحسابات وحقوق الوصول دون كلمات مرور أو رموز دخول |
| `data/uploads/` | الملفات الأساسية المحمية |
| `backups/` | نسخ احتياطية كاملة |

يتحدّث كتالوج المحتوى تلقائياً عند عمليات الحفظ والتعديل والحذف عبر التطبيق، وبعد الاستيراد. يحتوي المسودات والمحتوى المنشور والمجدول والمؤرشف. يعكس JSON الحالة الحالية؛ وقد تبقى نسخ مرفقات قديمة في مجلد المحتوى. لحفظ نقطة استعادة تاريخية كاملة، استخدم `npm run backup`.

لإعادة إنشائه يدوياً: `npm run export:content`. يمكن استيراد نسخته في تثبيت جديد بالأمر التالي:

```sh
node scripts/import-catalog.mjs data/content/catalog.json data/content/files
```

الاستيراد يضيف العناصر غير الموجودة، ولا يستبدل المحتوى الحالي. يُحفظ العنصر مسودة إذا كانت مرفقاته مفقودة.

الكود فقط يدخل Git. بيانات العملاء والمحتوى الخاص والمرفقات وكلمات البيئة والنسخ الاحتياطية مستبعدة بواسطة `.gitignore`، ويجب نقل مجلد البيانات إلى الاستضافة بشكل خاص. GitHub لا يستضيف خادم Node.js وقاعدة SQLite بمجرد رفع المستودع.
